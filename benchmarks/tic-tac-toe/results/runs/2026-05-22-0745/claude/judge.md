## Observations

- Single-file architecture cleanly serves two consumers: the same `<script>` runs the game in a browser and exposes `checkWinner`/`isDraw` on `globalThis` when loaded via `vm.runInThisContext` in Node. - The test file's choice of `vm.runInThisContext` over `vm.createContext` is deliberate and documented inline: it preserves shared `Array.prototype` so `deepStrictEqual` on the returned `line` array works. Small detail, but a thoughtful one most agents miss.

The restart flow itself is wired up and works — every other run of the suite produced a clean board with preserved scores.

- Accessibility taken seriously without being asked: `role="grid"`, `role="gridcell"`, `aria-label` per cell, `aria-live="polite"` on the status line.
