## Implemented markdown subset

- ATX headings: `#` through `######`
- Bold: `**text**`
- Italic: `*text*` and `_text_`
- Bold + italic: `***text***`
- Unordered lists: `-`, `*`, `+`
- Ordered lists: `1.`, `2.`, etc.
- One nesting level for lists via indentation
- Inline code with backticks
- Fenced code blocks with triple backticks and optional language label
- Inline links with safe URL validation
- Blockquotes using `>` lines
- Paragraphs with line breaks preserved inside a paragraph

## Not implemented

- Raw HTML passthrough
- Images
- Tables
- Horizontal rules
- Nested blockquotes
- More than one list nesting level
- Reference-style links
- Escaping rules beyond the supported subset above

## Security approach

The preview uses a hand-rolled renderer and sanitizer. It never trusts raw HTML from the markdown input:

- Raw HTML is escaped before being inserted into the preview.
- Link URLs are validated against an allowlist of protocols and relative forms.
- `javascript:` URLs are rejected.
- Unsafe links are rendered as inert text, not active anchors.
- Because the renderer only emits HTML generated by the script itself, inputs such as `<script>` tags and `<img onerror=...>` stay escaped and do not execute.
