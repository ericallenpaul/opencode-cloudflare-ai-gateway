## Observations

- **The CSP regression from the 1236 run is fixed**: `<meta http-equiv="Content-Security-Policy" content="default-src 'none'; style-src 'unsafe-inline'; img-src data:; script-src 'unsafe-inline'">` (line 16) now explicitly grants `script-src 'unsafe-inline'`. The 1236 run shipped the same defense-in-depth intent but missed the script-src directive, blocking the agent's own parser. This run learned from that failure — credit where it's due.
- **Two real bugs the test suite missed**: (1) Inline code body is not placeholder-protected, so `` `**bold**` `` renders as `<code><strong>bold</strong></code>` instead of `<code>**bold**</code>`. (2) List nesting produces invalid HTML — for `- a\n  - b\n- c`, the nested `<ul>` is emitted as a sibling of `<li>a</li>` (not its child), and `c` ends up in a separate top-level `<ul>` element. The functional R5 test only checks for the *sequence* of `<ul>/<li>` tags via `[\s\S]*`-spaced regex, which matches the broken output.
- **Two debug artifacts ship in the deliverable**: `initial-snapshot.md` and `post-interaction-snapshot.md` are Playwright accessibility-tree dumps that look like they were captured during testing and accidentally left in the output directory. They have no place in a user-facing bundle.
- **README has no H1 title**: the entire README begins at H2 level (`## Usage`). The five required documentation sections are present in substance but the title element is missing. Also the README is heavily AI-generated padding — "Finally" appears as a paragraph transition three times, the CSP is described in three separate paragraphs across two sections, and several paragraphs essentially repeat each other (e.g. "The renderer escapes all user input before formatting" appears in both Usage and Security).
- **Blockquote choice diverges from typical markdown**: each `>` line becomes its own `<p>` inside the `<blockquote>` instead of consecutive lines joining into one paragraph. Codified in the test (`<p>q1</p>[\s\S]*<p>q2</p>`) so this is the agent's intent, but it produces visually-spaced blockquotes for what users expect to be a single quoted paragraph.
- **Mobile layout doesn't stack**: `.split { display: flex }` with `width: 50%` panes and no media query. `mobile.png` shows the two panes still side-by-side at narrow viewport. Same gap that every opencode run in this benchmark has shipped.
