## Observations

- Security-first architecture: rather than escape on output per-node, the parser HTML-escapes the entire input once at the entry point and then matches markdown markers in the already-escaped text. This is elegant because ASCII markers survive escaping unchanged, while any user HTML is inert before parsing ever begins. The blockquote detector even keys off `&gt; ` (post-escape form) — a deliberate, well-commented design.
- The test file extracts the `<script id="parser">` block from `markdown.html` via regex and evaluates it in a `vm` sandbox, so tests exercise the exact code the browser runs (no parallel implementation drift). A separate wiring test loads BOTH script blocks against a fake DOM and a virtual `setTimeout` to prove the live-preview debounce fires within 250ms — this is the kind of test a frontier model writes that a cheap model usually skips.
- Rejected-URL handling is more defensive than the spec requires: instead of rendering the dangerous URL as literal text (which would still leak `javascript:alert(1)` to the page), the parser drops the URL entirely and renders only the link text. README documents this choice.
- The mobile screenshot (`mobile.png`) shows the panes remain side-by-side at narrow viewport widths instead of stacking — there's no `@media` query for column layout. The brief doesn't require responsive design, but on a real phone the textarea would be ~half the screen wide with all content wrapping.
- Minor implementation quirk: code-span extraction uses a literal placeholder ` CODE0 ` (with spaces) which could in principle collide with user text containing the same pattern. In practice the probability is near zero and the tests don't surface it, but a sentinel less likely to appear in prose (e.g., a non-printable or a UUID) would be more robust.
- Italic regex `/\*([^*\s][^*\n]*?[^*\s]|[^*\s])\*/` won't perfectly handle adjacent emphasis runs like `*a*b*c*`; that's a known CommonMark edge case that wasn't asked for and isn't tested. Worth noting but not a bug against the spec.
